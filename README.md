# Nexora Digital Solutions

# Project Overview

Nexora Digital Solutions is a responsive professional services website developed as part of the Week 4 Complete Web Development Project.

The website presents digital services such as web development, web applications, cloud solutions, UI/UX design, API integration, and website maintenance.

# Features

- Responsive multi-page website
- Home page
- About page
- Services page
- Contact page
- Responsive navigation
- Mobile menu
- Contact form validation
- Dark/Light mode
- Scroll animations
- Modern glassmorphism-inspired UI
- Responsive design for desktop, tablet, and mobile
- Accessibility-focused styling

# Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Grid
- Flexbox
- DOM Manipulation
- LocalStorage
- Intersection Observer API
